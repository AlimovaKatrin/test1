# Candidate Brief — Current User and Transactions

React and TypeScript mock interview covering API data, request states, DTO mapping, Retry, partial failure, and behavioural testing.

## Business goal

Build the smallest accessible, understandable implementation of Stage 1 within the existing starter. The API is local and deterministic.

## Stage 1 only

- Fetch the current user.
- Fetch recent transactions.
- Display the user’s full name.
- Display the transaction list.

## Evidence expected

- Explain your plan in English.
- Confirm the preview result; do not assume code works.
- Run `npm run check` before finishing.
- Prefer one meaningful behavioural test over low-value implementation assertions.
